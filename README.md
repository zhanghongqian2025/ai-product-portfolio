# 张洪千 AI 产品与交付作品集

介绍百融云创、齐乐无穷和北京赋界科技的产品与交付成果。

- 百鉴平台、十个智能体系列和代表性产品介绍
- 包晴天用户端、律师端与微信小程序
- 赋界科技官网、五个解决方案和五款 AI 产品
- 公司与类型筛选、关键词搜索、独立详情页和图片放大预览

## 本地运行

需要 Node.js 18 或更新版本，无需安装依赖。

```sh
npm start
```

访问 http://127.0.0.1:4173/。运行 `npm run check` 检查内容和资源。

## 发布

本项目为静态 HTML、CSS、JavaScript 页面，可通过 GitHub Pages 发布。选择 main 分支根目录，保留 `.nojekyll`。详情页使用哈希路由，适配仓库路径。

## 内容维护

产品内容位于 `data/portfolio.json`，图片位于 `assets/`。公司分工和代表智能体内容可直接更新 JSON。

产品截图与商店素材的版权归原权利人。本项目用于个人作品展示，不包含客户资料、账号凭据或内部审阅材料。
